⚙️ クラウド同期設定（Googleフォーム）

完全無料・APIキー不要でGoogleスプレッドシートへ自動送信します。Googleフォームを作成し、送信先URL（末尾が /formResponse）と、各項目のentry.IDを下に設定してください。URL未設定の間は今まで通りローカル保存のみで安全に動作します。

entry.IDの調べ方: フォームの入力欄を右クリック→「検証」→ input要素の name="entry.xxxxxxxxx" を確認。送信先URLはフォーム編集画面のプレビューを開発者ツールのNetworkタブで見て、formResponseで終わるリクエスト先を確認するのが確実です。
